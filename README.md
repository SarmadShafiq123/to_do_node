#SUMMARY

I made a basic To-Do backend using Node.js and Express.js.
It has 3 APIs:
1. POST to add task
2. GET to see all tasks
3. DELETE to remove a task by ID

I stored tasks in an array and tested everything using Postman.
I learned how to make APIs simply without database.
